9  Index files of the GDAC content

Index files of GDAC content provide means to retrieve, find, make statistics on GDAC files with respect to a selection of fields. There exists one index file for each of the following types of GDAC files: profile files, B-profile files, S-profile files, trajectory, tech and meta files. These index files are located at the root of the GDAC servers (both https and ftp):

  • https://data-argo.ifremer.fr/

  • https://nrlgodae1.nrlmry.navy.mil/pub/outgoing/argo/

  • ftp://ftp.ifremer.fr/ifremer/argo/

Some other more detailed index files exist on https://data-argo.ifremer.fr/etc/ repository. This repository is for internal expertise, only the detailed profile and S-profile index files will be described here-below.

These index files are auto-descriptive ASCII files; each index file contains:

  • A header with a list of general information: title, description, project name, format version, date of update, ftp root addresses, GDAC node

  • A table with a header containing the names of the columns followed by a line for each file of the GDAC that falls in this category of index. The table is a comma separated list.

Each index file is also available in a compressed version (gzipped with the .gz extension), also at the root of the GDAC servers.

In addition, for each update of an index file, an MD5 signature is produced. The MD5 signature file allows the user to check that the collected file is identical to the original file. MD5 signatures are recorded under the Ifremer https://data-argo.ifremer.fr/etc/md5/ repository with the following file naming convention: {index_file_name}.gz.md5.

9.1 Index of profile files

The index of profile files describes all individual profile files on the GDAC. It is named:

  • ar_index_global_prof.txt
ar_index_global_prof.txt definition

# Title : Profile directory file of the Argo Global Data Assembly Center

# Description : The directory file describes all individual profile files of the argo GDAC ftp site.

# Project : ARGO

# Format version : 2.0

# Date of update : YYYYMMDDHHMISS

# FTP root number 1 : ftp://ftp.ifremer.fr/ifremer/argo/dac

# FTP root number 2 : ftp://usgodae.org/pub/outgoing/argo/dac

# GDAC node : CORIOLIS

file,date,latitude,longitude,ocean,profiler_type,institution,date_update

  • file : path and file name. The file name contains the float number and the cycle number.
    Fill value : none, this field is mandatory

  • date : date of the profile, YYYYMMDDHHMISS
    Fill value : ” ” (blank)

  • latitude, longitude : location of the profile
    Fill value : 99999.

  • ocean : code of the ocean of the profile as described in reference table 13
    Fill value : ” ” (blank)

  • profiler_type : type of profiling float as described in reference table 8
    Fill value : ” ” (blank)

  • institution : institution of the profiling float described in reference table 4
    Fill value : ” ” (blank)

  • date_update : : date of last update of the file, YYYYMMDDHHMISS
    Fill value : ” ” (blank)

Note on date or position with a bad quality control flag in index files:

When the POSITION_QC or JULD_QC of the profile is 3 or 4 (probably bad, bad), the position is reported as missing in the index. In the index file, a missing date or position is set to “,,” (empty element).

9.2 Detailed index of profile directory files

The detailed index of profiles file describes all individual profile files of the GDAC with additional fields. The detailed index of profile files is limited to temperature, salinity and oxygen observations. It is located under the ’etc’ subdirectory and is named:

  • argo_profile_detailled_index.txt.gz
argo_profile_detailled_index.txt.gz definition

# Title : Profile directory file of the Argo Global Data Assembly Center

# Description: The directory file describes all individual profile files of the argo GDAC ftp site.

  • file: path and file name on the ftp site. The file name contains the float number and the cycle number.
    Fill value : none, this field is mandatory

  • date: date of the profile, YYYYMMDDHHMISS
    Fill value : ” ” (blank)

  • latitude, longitude : location of the profile
    Fill value : 99999.

  • ocean: code of the ocean of the profile as described in reference table 13
    Fill value : ” ” (blank)

  • profiler_type : type of profiling float as described in reference table 8
    Fill value : ” ” (blank)

  • institution: institution of the profiling float described in reference table 4
    Fill value : ” ” (blank)

  • date_update: date of last update of the file, YYYYMMDDHHMISS
    Fill value: ” ” (blank)

  • profile_temp_qc,profile_psal_qc,profile_doxy_qc : global quality flag on temperature, salinity and oxygen profile.
    Fill value: ” ” (blank)

  • ad_psal_adjustment_mean : for delayed mode or adjusted mode
    Mean of psal_adjusted – psal on the deepest 500 meters with good psal_adjusted_qc (equal to 1)
    Fill value: ” ” (blank)

  • ad_psal_adjustment_deviation : for delayed mode or adjusted mode
    Standard deviation of psal_adjusted – psal on the deepest 500 meters with good psal_adjusted_qc (equal to 1)
    Fill value: ” ” (blank)

  • gdac_date_creation : creation date of the file on GDAC, YYYYMMDDHHMISS

  • gdac_date_update : update date of the file on GDAC, YYYYMMDDHHMISS

  • n_levels :maximum number of pressure levels contained in a profile

Fill value: ” ” (blank)
